# Codex page

Part of the frontend guide, see [CLAUDE.md](../CLAUDE.md). The backend side is in [codex.md](../../backend/docs/codex.md).

- `/codex` (`pages/Codex/`, a lazy route like the others, so Tiptap is a chunk of its own and not in the main bundle) shows «Кодекс Інарі» to every logged-in user: the title, the cover `public/codex-cover.png` with the caption «Правила Лисятника» (part of the page, not of the document), the text, and under it «Редакція від <day>» once a text has been saved (no line before that). The sidebar item and the card of the home page lead here. There is no `VITE_CODEX_URL` any more, and no item of the sidebar opens a page outside the site.
- The text is a Tiptap editor (`@tiptap/react` with `StarterKit`, 3.x), read-only until an admin (`SUBJECTS.EDIT_CODEX`) presses «Редагувати». `codexExtensions` (`const/extensions.ts`) turns off what the text does not have (lists, quotes, code, strike, underline) and allows headings of level 2 and 3 and links to `http`, `https` and `mailto`. `openOnClick` of the link is `false`: Tiptap's handler opens a link by a click only while the editor is editable, so with it on the caret could never enter a link to change it. Reading works without it, the link is an `<a target="_blank">`. It has to stay the same set as `CodexContent` on the backend, or a save is refused with 400. `Codex` loads the text (`useCodexStore.getCodex`), shows «Не вдалося завантажити Кодекс» with a retry button when that fails, and makes `CodexPage` only after the answer, because the editor takes its content once, when it is created, and the store may still hold the text of an earlier visit.
- Editing: `CodexToolbar` (bold, italic, link, «Розділ», «Підрозділ», rule, undo, redo; its state comes from `useEditorState`, and the buttons keep the selection with `preventDefault` on `onMouseDown`), `LinkDialog` for an address (`normalizeHref` turns «example.com» into «https://example.com»; `isValidHref` refuses a space, because the browser's `URL` takes «https://a b» and the Node of the backend does not; the editor uses it as `isAllowedUri` too, so a pasted link the backend would refuse does not become a link), «Зберегти» (it waits for a change: the document of the editor against the document it had when the editing began, compared with `doc.eq`) and «Скасувати» (asks first when there is a change). The server answers with the text as it wrote it, and the store keeps that.
- A change that is not saved is guarded: `useBlocker` asks before a move inside the site and `beforeunload` before the tab is closed, both with `ConfirmDeleteDialog` (`autoFocusCancel` for the first). `useBlocker` needs a data router, which is why `src/index.tsx` is `createBrowserRouter` with one route that takes every path (`Root.tsx`) and not `BrowserRouter`. The pages are still laid out by `router/index.tsx`.
- The look is `Codex.module.scss`: one column of 780px, `.document :global(.ProseMirror)` holds the typography (bold numbers, `h2` and `h3`, the rule, links), `.editing` puts the text in a frame, and `.toolbar` is sticky. The space between clauses is the margin of a paragraph, not empty paragraphs.
